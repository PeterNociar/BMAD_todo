Todo app: design directions, round 1

Four calm, minimal directions for the single screen: input at top, one list below. Open tasks oldest first with an age colour and label; completed tasks after, most recent first. Same content in every direction. Each shows laptop (with one row in hover state), phone at 360px, and the empty state.

A. PaperWarm, airy, humanist. Age colour lives in a small dot beside the age label.

A warm off-white page with generous line spacing and a humanist sans, so the list reads like a tidy note rather than software. The only colour is a small dot next to each age label; the label itself stays a quiet, darkened tint of the same hue so it passes AA. Completed tasks are struck through and faded, so they recede without disappearing.

B. LedgerCool, compact, tabular. Age colour lives in a thin left bar on each row; monospace labels right-aligned.

A cool neutral ledger: tight rows, hairline dividers and a monospace age column right-aligned so ages scan like numbers in a table. Colour is a 3px bar on the left edge of each open row, so the eye can sweep the column of bars to see what is going stale. Completed rows keep plain muted text with a check mark and no strikethrough.

C. SoftFriendly, rounded, card-based. Age colour is a very light wash on the card plus a coloured label pill.

Each task sits on its own rounded card with a whisper of its age colour washed across the background, so staleness is felt as a gentle warming of the list. Age labels are small pills in the full hue with dark text inside, and the rounded type keeps everything approachable. Completed tasks become plain grey cards with a filled check.

D. NightDark, crisp, grotesk. Age colour lives on the label text itself plus a soft glowing dot.

A near-black canvas with crisp grotesk type, for people who keep a tab open all evening. The age label is set in the age colour and paired with a small dot that glows faintly, so the colour reads as light rather than paint. Completed tasks drop to low-contrast grey and stay out of the way.
